# 🍓 FrutiMerca

Sitio web oficial de **FrutiMerca** — Frutas frescas del Mercado José Mascote, Guayaquil, Ecuador.

## 🌐 Sitio Web

👉 **[Visitar la web](https://jonathanyc02.github.io/FrutiMerca/)**

## 📋 Descripción

Plataforma de venta online de frutas frescas al por mayor y menor. Incluye:

- 🛒 Carrito de compras
- 💳 Sistema de pedidos por transferencia bancaria
- 📸 Subida de comprobantes (vouchers)
- 📊 Registro automático de pedidos en Google Sheets
- 📱 Notificaciones por WhatsApp
- 👨‍👩‍👦 Sección "Conócenos" con la historia familiar
- 📜 Términos y condiciones
- ⚙️ Panel de administración

## 🍓 Productos

- Frutilla Primera, Segunda, Tercera y Cuarta
- Mora de Castilla
- Granadilla Selecta
- Claudia (Ciruela de temporada)
- Durazno
- Aguacate
